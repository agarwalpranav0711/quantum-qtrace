## 1. Explicit Academic Disclosures

In accordance with scientific rigor, Q-TRACE makes the following explicit boundary disclosures regarding its quantum computing capabilities:

```
+-------------------------------------------------------------------------------+
|                       EXPLICIT SCIENTIFIC DISCLOSURES                         |
+-------------------------------------------------------------------------------+
| 1. Simulation Only:                                                           |
|    - Q-TRACE executes on classical CPU hardware using Qiskit Aer statevector  |
|      simulators. It does NOT connect to physical superconducting or trapped-  |
|      ion QPUs (e.g. IBM Eagle / Heron).                                       |
| 2. No Computational Quantum Advantage:                                        |
|    - Classical execution of 4x4 image XOR on CPU is ~1,300x faster than      |
|      simulating the quantum circuit. There is zero speedup in production.      |
| 3. Micro-Patch Boundary:                                                      |
|    - Quantum circuits are mathematically and practically restricted to 4x4    |
|      patches. Simulating full 1080p images in statevector format would require |
|      281 Terabytes of RAM, which is globally impossible on classical hardware. |
| 4. Idealized Noise-Free Simulation:                                           |
|    - The simulation assumes perfect gate fidelities and zero decoherence      |
|      (T1/T2 = infinity). Real physical QPUs would suffer gate infidelities,   |
|      readout errors, and crosstalk requiring quantum error correction (QEC).  |
| 5. State Preparation Bottleneck:                                              |
|    - Mapping classical pixel intensities into quantum superposition via       |
|      multi-controlled gates requires O(N) classical preparation time. The     |
|      hypothetical O(1) comparison advantage is strictly in the arithmetic    |
|      phase once the superposition is already loaded.                          |
+-------------------------------------------------------------------------------+
```

## 2. The Legitimate Scientific Role of Q-TRACE's Quantum Modules

Despite these hardware limitations, Q-TRACE's quantum implementation fulfills four vital academic research functions:

1. **Algorithmic Correctness Prototyping:** Validates that NEQR pixel encodings, coordinate indexing, and transverse CNOT comparators produce bitwise exact parity with classical difference equations.
2. **Measurement Readout Modeling:** Provides empirical verification of stochastic quantum readout bounds (Coupon Collector problem) and demonstrates robust handling of unobserved coordinate data.
3. **Hardware Readiness:** The circuits generated by Q-TRACE (`QuantumComparator16Q` and `QuantumComparator12Q`) compile to standard OpenQASM 3.0 representations, ready to be dispatched to physical QPU cloud backends whenever commercial quantum hardware reaches sufficient qubit quality.
4. **Pedagogical Transparency:** Allows forensic analysts and computer science students to inspect real quantum circuits, visualize gate-level operations, and understand quantum image mathematics without misleading claims of quantum supremacy.

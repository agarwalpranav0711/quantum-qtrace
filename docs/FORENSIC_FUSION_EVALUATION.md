## 1. Mathematical Formulation of Consensus Fusion

Let $R_t = \{r_{t, 1}, r_{t, 2}, \dots, r_{t, m_t}\}$ represent the set of candidate bounding boxes generated by forensic technique $t \in \{\text{ELA}, \text{Noise}, \text{CMFD}\}$.

Each bounding box is parameterized as $r = (x, y, w, h, s)$, where $(x, y)$ are top-left pixel coordinates, $(w, h)$ are dimensions, and $s \in [0, 1]$ is the local anomaly score.

### Spatial IoU Clustering:
Given two candidate regions $r_a$ and $r_b$, their spatial Intersection-over-Union is:

$$\text{IoU}(r_a, r_b) = \frac{\text{Area}(r_a \cap r_b)}{\text{Area}(r_a \cup r_b)}$$

Candidate regions across different techniques are merged into a unified consensus cluster $C$ if:

$$\exists r \in C \quad \text{such that} \quad \text{IoU}(r, r_{cand}) \ge \theta_{\text{IoU}} \quad (\text{default } \theta_{\text{IoU}} = 0.20)$$

### Merged Bounding Box Geometry:
$$x_{fused} = \min_{r \in C} r.x, \quad y_{fused} = \min_{r \in C} r.y$$
$$w_{fused} = \max_{r \in C} (r.x + r.w) - x_{fused}, \quad h_{fused} = \max_{r \in C} (r.y + r.h) - y_{fused}$$

### Cross-Validation Confidence Elevation:
The confidence score $S_{fused}$ of a merged consensus region is computed as a function of the average baseline anomaly score plus a bonus proportional to the number of distinct orthogonal contributing physical domains $K$:

$$S_{fused} = \min\left(0.99, \; \frac{1}{|C|} \sum_{r \in C} r.s + 0.15 \times (K - 1)\right)$$

Where $K = |\{t \in \{\text{ELA}, \text{Noise}, \text{CMFD}\} \mid \exists r \in C \text{ generated by } t\}|$.

## 2. Evaluation on Complex Vehicular Claims

1. **Monolithic Anomaly Suppression:** A single technique flagging an area with score $0.70$ remains at confidence $0.70$.
2. **Multi-Signal Corroboration:** When ELA (compression) and Noise (sensor hardware) both independently flag an overlapping bumper boundary, the consensus score is elevated:
$$S_{fused} = 0.70 + 0.15 \times (2 - 1) = 0.85\text{ (HIGH CONFIDENCE)}$$
3. **Audit Trail Completeness:** The resulting `RegionOfInterest` schema records the exact technique lineage in `contributing_techniques: ["Error Level Analysis", "Sensor Noise Inconsistency"]`, providing clear evidentiary provenance in courtroom reports.
